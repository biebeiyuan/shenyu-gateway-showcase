# Shenyu Gateway 交互逻辑地图

一个纯前端、全脱敏的交互原型，用四条可播放的请求路径展示长期 AI 交互系统如何处理上下文、记忆、工具调用、上游适配、流式响应与错误反馈。

它不是生产网关的控制台，也不会连接任何真实服务。页面中的用户消息、处理结果和运行证据均为合成内容。

## 可以体验什么

- 切换「普通长期对话」「明确提起旧事」「混合工具调用」「上游真实报错」四种场景。
- 播放、暂停、逐步前进或回退一条请求，观察每个节点的状态变化。
- 点击任意节点，从「体验视角」理解产品判断，从「系统视角」查看输入、输出和验证证据。
- 通过底部时间线直接跳转到任一步骤，比较不同场景经过或跳过的系统区域。

## 作品重点

- **交互抽象：** 把复杂网关拆成可操作的体验地图，而不是一张只能阅读的架构图。
- **产品边界：** 明确当前对话优先、记忆稳定、工具归属、错误透传和隐私保留范围。
- **验证思维：** 每个节点同时说明用户问题、产品判断、输入输出与可观察证据。
- **隐私设计：** 无 API、无生产代码、无真实日志、无提示词、无用户记忆和密钥。

## 技术栈

Vue 3、TypeScript、Vite、Vue Flow、Lucide Icons。所有演示场景都来自本地静态数据。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 项目结构

```text
src/
├── components/GatewayNode.vue  # 地图节点及状态呈现
├── data/gateway.ts             # 脱敏节点、连线与四条静态场景
├── App.vue                     # 播放控制、地图、详情与时间线
├── style.css                   # 响应式视觉系统
└── types.ts                    # 展示数据契约
```
